Kirim Email

Panduan Setup:
1. Daftar akun gratis di EmailJS.com
2. Dapatakan Service ID, Template ID, dan User ID
3. Ganti nilai di bagian JavaScript dengan ID Anda
Note:
Jika pesan tidak ada di bagian utama Gmail kamu, maka mungkin pesan tersebut terkirim ke folder "Promosi" atau "Spam". Periksa folder tersebut atau gunakan fitur pencarian.
